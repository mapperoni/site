A map page lets respondents add information to a shared map. Use layers to organize what they can add. {% .lead %}

## Add a map page

In the project editor, click **Insert Page** and choose **Map Page**. Then click **Edit Map** on the new page.

## Add layers

Click **Add Layer** to create a point layer. A layer is a category for pins on the map. For example, someone using mapperoni to create a "Fix Me" survey might add separate layers for _Repairs_, _Cleanups_, or _Other issues_. When someone adds a pin, they choose the layer it belongs to.

Open a layer to give it a clear name and optional description. You can also add form fields to collect details for every pin in that layer, such as a description, photo, or contact information.

Use the color button beside a layer to change its color. From the same menu, you can:

- Hide the layer to remove it from the public map and stop new responses while keeping its existing data in the editor.
- Choose whether pins are visible to everyone or only to the person who added them.

## Map settings

Open **Map Settings** to choose a vector or satellite basemap. You can ask for the respondent's device location when the map opens, or set a custom center and zoom level. Use **Capture Current Extent** to use the view you are looking at now.

Keep layer names short and specific. Respondents see them when deciding what to add to the map.
